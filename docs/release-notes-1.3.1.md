# BangumiBar v1.3.1

## 版本简介

本版本聚焦追番核心交互修复、macOS 原生视觉精修、性能与稳定性治理，并补齐了右键批量标记、完整收藏状态切换与自定义镜像域名等高频能力。

## 主要更新

### 追番体验与界面优化

- **层级与 macOS 风格精修**：将「动画 / 书籍 / 游戏」调整至状态筛选栏上方并改用 macOS 分段控件样式；补齐 `@media (prefers-color-scheme: light)` 浅色外观自适应，统一设置页与主界面的细线条 SVG 图标
- **全收藏状态与动态文案**：筛选栏补齐 **看过 / 搁置 / 抛弃**（共 5 种状态），并按条目类型自动切换对应文案（动画：在看/想看/看过；书籍：在读/想读/读过；游戏：在玩/想玩/玩过）；动画卡片同步显示收藏状态标签
- **右键「看到第 N 集」批量标记**：右键分集圆点新增「看到第 N 集」，调用 Bangumi 批量分集接口一次标记前序未看集数，支持乐观更新与按集精确回滚
- **用户个人评分与半星打分重做**：条目卡片新增 Bangumi 经典迷你五星展示用户个人评分（点击即可修改），修改弹窗准确回显并支持清除；重构半星裁剪逻辑，支持左右半区实时预览、按住拖动选分、键盘方向键微调及弹性微动画
- **清理重复按钮与精准搜索**：移除卡片底部重复的「修改状态」按钮，统一收口到标题行编辑图标；搜索改为严格作用于当前所在列表并保留待看优先排序
- **自定义镜像域名**：设置页支持手动配置任意合法 Bangumi 镜像域名（支持一键重置默认 `bangumi.one`），主进程出网白名单同步动态放行

### 关键缺陷修复

- **分集乐观更新与回滚**：修复点击分集时误覆盖内层 `episode.episode.type` 导致已看本篇被当成 OP 过滤的问题；打通右键菜单与卡片状态同步，接口失败时按单集精确回滚并拦截误弹完结框
- **鉴权刷新与通知开关**：引入带状态码的 `BangumiApiError` 与并发刷新互斥锁，修复 401 刷新死循环与短暂断网误登出；桌面通知严格遵循设置页「新集提醒」开关且仅在接口成功后发送
- **评分提交修复**：修正修改收藏接口以 Bangumi v0 标准字段 `rate` 提交评分，并兼容 `204` 空响应
- **双窗口同步与 macOS 托盘兜底**：打通独立设置窗与主悬浮窗的设置及登录态实时同步，修复独立设置窗关闭按钮；新增启动自动弹出主窗口、全局快捷键 `Cmd + Shift + B`、macOS 托盘边界钳位及刘海屏 / `height=0` 隐藏态兜底

### 性能、安全与工程清理

- **请求限流与缓存治理**：为卡片 `getSubject` / `getEpisodes` 增加上限 4 的并发队列与同 ID 去重，优先复用列表内嵌条目摘要；分页集合拉取改为按批顺序并发；启动时自动清理过期 `localStorage` 与内存缓存，并在写入触发配额上限时自动回收重试
- **列表渲染优化**：为列表过滤与排序增加 `useMemo`，卡片增加 `React.memo`，避免悬停集数圆点时触发全列表重排
- **主进程健壮性**：`open-external` 限制仅放行 `http:` / `https:` 协议；放送表抓取补齐 15 秒超时；日志改为异步写入并增加 2MB 启动轮转
- **依赖清理**：移除 `package.json` 中未使用的 `jimp`、`pngjs`、`has-tostringtag` 开发依赖
