# BangumiBar v1.3.0

## 版本简介

本版本聚焦 macOS 菜单栏体验与追番数据展示：新增条目名称的中/原文显示开关，修正 OP/ED 被计入详情分集和待看数量的问题，并重构了托盘图标的显示方式与悬浮窗的弹出/隐藏状态管理，减少菜单栏弹窗丢失或闪退式的交互异常。

## 主要更新

### 条目名称显示开关

- 新增条目名称显示模式切换，可一键在中文译名和 Bangumi 原始名称之间切换
- 搜索不跟随当前显示语言切换，始终同时匹配中文译名与原始名称
- 通知、卡片和其他列表展示统一使用同一套标题选择逻辑，避免名称显示不一致

### 分集统计修复

- 详情分集列表与待看数量现在会排除 OP/ED，只统计本篇内容
- 缺少集数或类型不明确的数据仍按保守规则处理，避免误隐藏正常分集

### macOS 托盘与悬浮窗

- 菜单栏图标改用 bgm.tv 风格的 template icon，自动适配浅色/深色菜单栏
- 悬浮窗的显示阶段拆分为 pending / showing / hiding / hidden，等待页面加载完成后再真正展示，降低首次点击看不到窗口的概率
- 点击托盘时抑制窗口失焦导致的自动隐藏，重复点击也能在显示与隐藏之间正确切换
- 失焦自动隐藏加入托盘激活时间判断，保持 macOS popover 的使用手感
- 悬浮窗淡出过程会通知渲染层播放退出动效，隐藏后再复位状态

### 打包脚本

- `build.sh` 支持平台与架构参数叠加组合，可显式构建 arm64 / x64 / universal，也可进入快速验证用的 `--dir` 模式
- `release.sh` 改用 `ditto` 打包 macOS `.app`，保留 Electron Framework 中的符号链接，避免 zip 内容膨胀且运行结构损坏
- Windows NSIS 安装包补回多语言许可协议资源

## 发布资产

## 升级说明

- 直接覆盖安装即可，本地登录状态与缓存不受影响
- 如果旧实例仍在菜单栏运行，请先退出旧版本，再安装并启动新版本
